How it works

From a formula to a ranked result in seconds.

  1. Describe the material

    Type a formula such as La0.6Sr0.4Co0.2Fe0.8O3 and a temperature, or enter every descriptor yourself.

  2. The models predict

    Machine learning trained on measured data, combined with documented physics relations for the derived properties.

  3. Understand and compare

    See every value, how it compares with LSC, how stable the material is, and which features moved the answer.
